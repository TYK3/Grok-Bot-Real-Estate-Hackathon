## Noise cancellation

### What it does

Cleans inbound caller audio on the **agent side** before Silero VAD, STT, and turn detection see it.
Runs inside the **agent worker process**, not inside the LiveKit media server (Podman).

```
Browser mic → LiveKit room → agent receives track → [NC filter] → VAD / STT / LLM
```

Apply NC **once**. If enabled on the agent, disable Krisp/noise filters in the browser client.

### Where it is configured (current API)

Pass to `session.start()` via `RoomOptions` → `AudioInputOptions` → `noise_cancellation`.
Do **not** use deprecated `RoomInputOptions` (NatWest demo uses old API).

```python
from livekit.plugins import noise_cancellation
from livekit.agents import room_io

await session.start(
    room=ctx.room,
    agent=MyAgent(),
    room_options=room_io.RoomOptions(
        audio_input=room_io.AudioInputOptions(
            noise_cancellation=noise_cancellation.BVC(),
            sample_rate=24000,
            num_channels=1,
            frame_size_ms=50,
            auto_gain_control=True,
            pre_connect_audio=True,
            pre_connect_audio_timeout=3.0,
        ),
    ),
)
```

Runtime selector (BVC vs telephony by participant type):
```python
from livekit import rtc

noise_cancellation=lambda params: (
    noise_cancellation.BVCTelephony()
    if params.participant.kind == rtc.ParticipantKind.PARTICIPANT_KIND_SIP
    else noise_cancellation.BVC()
)
```

### Console mode does NOT use NC

`uv run python src/agent.py console` talks directly to Mac mic — no room track, no `RoomOptions`, no BVC.
NC only applies when a remote participant connects via web UI / LiveKit room.

### Plugin options (pick ONE for the noise_cancellation slot)

| Package | Install | Import | Models |
|---------|---------|--------|--------|
| livekit-plugins-noise-cancellation | `uv add "livekit-plugins-noise-cancellation~=0.2"` | `from livekit.plugins import noise_cancellation` | `NC()`, `BVC()`, `BVCTelephony()` |
| livekit-plugins-ai-coustics | `uv add livekit-plugins-ai-coustics` | `from livekit.plugins import ai_coustics` | `QUAIL_L`, `QUAIL_VF_S` |
| livekit-plugins-krisp | separate package | `from livekit.plugins import krisp` | `KrispVivaFilterFrameProcessor(...)` |
| livekit-plugins-dtln (community) | third-party | `from livekit.plugins import dtln` | `dtln.noise_suppression()` |

#### livekit-plugins-noise-cancellation (Krisp via LiveKit)

| Model | Use when |
|-------|----------|
| `NC()` | Standard background noise suppression |
| `BVC()` | Browser / web / mobile — also removes competing voices |
| `BVCTelephony()` | SIP / phone callers |

**Cloud vs self-hosted:** Officially a **LiveKit Cloud** feature. LiveKit agent starter says omit when self-hosting the media server. Our project uses Podman LiveKit (`ws://localhost:7880`) — not the documented path for BVC; may work for dev but not guaranteed.

#### livekit-plugins-ai-coustics

Two auth modes:
- `auth=ai_coustics.LiveKitCloud()` — default, needs LiveKit Cloud SFU (metered)
- `auth=ai_coustics.AiCousticsApi(license_key="...")` — works with **self-hosted** LiveKit server

```python
noise_cancellation=ai_coustics.audio_enhancement(
    model=ai_coustics.EnhancerModel.QUAIL_L,       # noise suppression (like NC)
    # model=ai_coustics.EnhancerModel.QUAIL_VF_S,  # voice isolation (like BVC)
    auth=ai_coustics.AiCousticsApi(license_key="YOUR_KEY"),  # self-hosted
)
```

#### livekit-plugins-krisp (different from noise_cancellation package)

Fine-grained control; runs in-process on agent:
```python
processor = krisp.KrispVivaFilterFrameProcessor(
    noise_suppression_level=100,  # 0–100
    frame_duration_ms=10,
)
noise_cancellation=processor
```

#### Self-hosted recommendation

If media server is Podman (not LiveKit Cloud):
- Prefer **ai-coustics + own API key**, **krisp viva**, or **dtln** (OSS)
- Avoid relying on `noise_cancellation.BVC()` for production

---

### Cloud vs self-hosted (quick reference)

| Component | Self-hosted Podman (`localhost:7880`) | LiveKit Cloud |
|-----------|--------------------------------------|---------------|
| Media server (SFU) | Your Podman | LiveKit hosted |
| Agent worker | Your machine (works with both) | Your machine or Cloud deploy |
| `noise_cancellation.BVC()` | Not officially supported | Supported (metered for BVC) |
| ai-coustics default auth | No — use `AiCousticsApi` key | Yes — `LiveKitCloud()` |
| Console mode NC | Never applies | Never applies |
